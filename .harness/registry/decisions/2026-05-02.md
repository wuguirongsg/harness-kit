## Stop hook 设计：用 harness dirty 检测代替 flag 文件

- **选择**：Stop hook 通过 `git status --porcelain -- .harness` 判断是否触发 SESSION_END，不使用 flag 文件
- **原因**：flag 在 SessionStart 写入、第一次 Stop 消费，多轮对话后续 Stop 就无法触发；dirty 检测天然幂等——SESSION_END 执行完 git commit 后 harness 就干净了，下次 Stop 自动放行，无需额外状态管理
- **影响**：session-start.sh 无需修改；session-end.sh 只依赖 git 状态
- **不可推翻**：否，若 SESSION_END 协议不再以 git commit 结束，需重新评估触发条件
