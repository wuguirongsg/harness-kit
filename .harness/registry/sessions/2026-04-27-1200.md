## 完成内容

### install.sh 修复
- 支持传入目标路径参数：`bash install.sh /path/to/project`
- `BASH_SOURCE[0]` 改为 `${BASH_SOURCE[0]:-$0}`，兼容 zsh 执行
- 改为逐项复制 .harness 内容，排除本项目自身的 session 记录（解决 session 文件污染用户项目的问题）
- 所有路径改用 `$TARGET_DIR` 绝对路径，不再依赖 `cd` 后的工作目录

### 新增 install.ps1
- PowerShell 版本，逻辑与 install.sh 完全对应
- 支持 `install.ps1 C:\path\to\project` 传参
- 使用 `$PSScriptRoot` 替代 `BASH_SOURCE`

### Windows 支持方案评估（结论）
- hooks 依赖 `bash` 命令：装了 Git for Windows 的用户直接可用，无需 .cmd 改造
- 决定：只写 install.bat，README 注明 Git for Windows + Python3 为前置依赖
- 不做纯 cmd.exe 的 .cmd hooks（价值不高，工作量 4x）
